病隙碎笔：MLP复现手记

发表于 2026-10-06 分类于 从零实现

序

一开始并不知道为什么要学MLP，直接把一层线性层的值给到另一层线性层不就好了，直到我做了这个实验，把两层线性层和两层MLP作比较。

一开始我的初始化是这样的：

用这个初始化的数据跑10000步出来的两个模型最终的loss和accuracy是这样的。

MLP loss MLP accuracy 2-layer-FC loss 2-layer-FC accuracy
0.262 0.887 0.261 0.887

这两个模型最后的结果完全一样，在 scale 比较小的时候因为 $dZ_1=dA_1(1-A_1^2)$，而 $w_1$、$b_1$ 都趋近于 0，所以 $dZ_1$ 就约等于 $dA_1$，也就是说，$A_1$ 的隐藏层几乎失去作用。

不过这个“一样”只是暂时的：把 scale = 0.01 的这一组多跑一会儿，就能看到它其实是踩着两个台阶走下去的。下面这张图把同一组实验跑到 10 万轮，每 10 轮记一个点，横轴就是这 10000 个记录点（右边的 10000 对应第 10 万轮，图中虚线是纯线性模型那条 0.887 的天花板）：

台阶 记录点（约多少轮） loss accuracy 现象
① 抢跑 0 → 100（约 1000 轮） 0.693 → 0.264 0.28 → 0.88 只学得动输出层，先学成纯线性模型，一步踩到它的天花板
② 假平台 100 → 6600（约 6.6 万轮） ≈ 0.262 ≈ 0.885 彻底平掉，和 2-layer-FC 的成绩一模一样；快突破时 accuracy 还会先掉到 0.875
③ 突破 6600 → 7000 0.26 → 0.048 0.885 → 0.99 几百个记录点之内跌到底，隐藏层终于开始起作用
④ 收敛 8000 → 10000（约 10 万轮） ≈ 0.004 1.000 甩开线性天花板，最后跑到满分

前 6600 个记录点里，loss 一直平在 $\approx0.262$、accuracy 一直在 $0.88\sim0.89$ 之间晃，和纯线性模型的成绩完全重合，直到第 6770 个记录点附近（约 6.8 万轮）loss 才第一次跌破 0.2。所以前面“跑 10000 步，两个模型的 loss 和 accuracy 一模一样”的结论，其实只是它卡在台阶②上还没开始突破：scale 这么小不是学不会，是慢得离谱。

之后，我又让scale = 5得到了更好的结果。

MLP loss MLP accuracy 2-layer-FC loss 2-layer-FC accuracy
0.006 1 0.329 0.86

MLP取得了惊人的成绩，而双层线性层一直在原地踏步，这就是为什么要用MLP。

MLP的求导与原因

我们先解释MLP怎么求导，再说为什么要用到MLP。这是我做实验的数据集：

做的是一个叠加半圆形的分类任务，loss函数选择的是和sigmoid函数配套的BCE，下面是训练代码：

我们先讲为什么要用 sigmoid：$\sigma(x)=\frac{1}{1+e^{-x}}$，通过分析可知，无论 $x$ 怎么取值，函数的输出值都能保证在 $(0,1)$ 之间，与概率的分布相同，况且在 0 处取到导数的最大值，这就能感受到数值的细微变化，让二分类成为可能。

那么为什么要用 BCE 作为 loss 函数呢？这里我们先看 sigmoid 的导数。因为我们用的是反向传播，会先得知 $A_2$ 的值，所以当 $A_2=\sigma(Z_2)$ 时，我们要用 $A_2$ 去表示 $Z_2$。先对 $A_2$ 求导得

$$\frac{dA_2}{dZ_2}=\frac{e^{-Z_2}}{\left(1+e^{-Z_2}\right)^2}=A_2\left(1-A_2\right)$$

中间那一步是把 $e^{-Z_2}=A_2^{-1}-1$ 代进去。这时我们再分析 BCE 函数：一方面对 $A_2$ 取对数，能让趋向于 0 的极端值显得更尖锐；另一方面

$$\frac{\partial l}{\partial A_2}=\frac{1}{n}\cdot\frac{A_2-Y}{A_2\left(1-A_2\right)},\qquad dZ_2=\frac{\partial l}{\partial A_2}\cdot\frac{dA_2}{dZ_2}=\frac{1}{n}\left(A_2-Y\right)$$

它正好能把 $\frac{dA_2}{dZ_2}$ 消掉，直接算出干净的 $dZ_2$。之后的过程就是反向传播，得知上一层的导数推知下一层的导数，这点在线性回归有详细解释，这里就不多赘述。

Xavier、LeCun与初始化

我原本以为，这个是用来解释为什么scale = 0.01时MLP趋向于线性的，但研究之后才知道，这是用来解释如何才能让多层神经网络求出来的方差不要过大的，也就是说，这是为之后复现attention is all you need做准备的，那我这就稍微解释一下。

为什么要初始化

我们先看 scale 过小的情况，$Z_1$ 基本集中在 0.01 左右，这时 $A_1$ 也基本趋向于 0，$\tanh$ 接近于线性，多轮训练并没有取到它作为非线性隐藏层的变换效果；再看 scale 过大的情况，$|A_1|\approx1$，导致 $dZ_1=dA_1\left(1-A_1^2\right)$ 里的 $\left(1-A_1^2\right)$ 趋向于零，也就是说，有很多的参数训练速度极慢。

况且，每次前向传播会让噪声方差放大一次：

$$\mathrm{Var}(Z_2)=n_{in}(Z_2)\cdot\sigma^2\cdot\mathrm{Var}(A_1)$$

这里的 $\mathrm{Var}$ 表示 $Z_2$ 和 $A_1$ 的方差，$n_{in}(Z_2)$ 表示 $Z_2$ 输入的参数量，$\sigma$ 表示一开始取正态分布时的标准差，也就是说每次前向传播都会让方差乘上 $n_{in}\sigma^2$，如果不加调整，深度学习到最后肯定充满了最初几层的噪声；同理反向传播的时候也会让噪声放大一次：

$$\mathrm{Var}(dA_1)=n_{out}(Z_2)\cdot\sigma^2\cdot\mathrm{Var}(dZ_2)$$

这里的 $n_{out}(Z_2)$ 表示反向传播时 $Z_2$ 输出的参数量。要想保证输入的噪声不影响之后的学习，就必须让 $n_{in}(Z_2)\sigma^2=1$；要想保证输出的噪声不影响之后的学习，就必须让 $n_{out}(Z_2)\sigma^2=1$，这两者在 $n_{in}$、$n_{out}$ 不相等的情况下无法同时满足。因此我们只能求出一个 $\sigma$ 的大致区间，取

$$\sigma^2=\frac{2}{n_{in}+n_{out}}$$

这时大约能保证噪声方差不会逐渐放大。

按这个式子算：产生 $Z_1$ 的那一层 $n_{in}=2$、$n_{out}=16$，得 $\sigma\approx0.33$；产生 $Z_2$ 的那一层 $n_{in}=16$、$n_{out}=1$，得 $\sigma\approx0.34$。两者差别不大，实验里干脆都取 0.33。简单起见，我们就只看 $Z_1$。

耳听为虚，眼见为实，我们在python里面跑一遍就知道了。

最后得到的结果是这样的：

scale Z1sigma A1sigma flat
0.01 0.011 0.011 0
0.1 0.123 0.12 0
0.33 0.388 0.327 0
1 1.021 0.592 0.031
5 6.555 0.905 0.592

确实如我们所料，在0.01~0.33时，A1的flat = 0，也就是说基本都分布在±0.99之内，有训练的能力，而大于0.33时，std正比于σ变大，往后传播的噪声方差变大，会让之后训练的噪声占比增加，况且scale = 5时，flat = 0.592，也就是说大于半数的A1都分布在0.99之外，起点很不健康。

但是，这里的sigma的分析说明的是噪声在前向和反向传播中的占比，而非代表了训练收敛的速度，因为按我们这个模型，收敛速度最快的是scale=5的情况。
